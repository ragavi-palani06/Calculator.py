# Python Tkinter Calculator

A professional GUI Calculator application built using **Python and Tkinter**.

## Features

* Addition, Subtraction, Multiplication and Division
* Numbers 0–9
* Decimal numbers
* Clear button
* Backspace/Delete
* Percentage calculation
* Division by zero handling
* Simple and clean GUI

## Technologies Used

* Python
* Tkinter

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python calculator.py
```

## Project Purpose

This project was created to practice **Python GUI development, functions, events, widgets, and button commands using Tkinter**.
